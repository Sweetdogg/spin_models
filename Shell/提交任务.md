**lib使用说明**

- 在当前目录创建一个文件夹命名要求processed_data

- 创建一个.py文件

  ```python
   import lib as pt
   pt.plot_data('out.dat','x',[8,16],[5,1,1])
  ```

- plot_data参数说明

1. out.dat是数据文件，第零列要求是尺寸数据如L=8，第一列x轴参数，后面是数据，上述最后[5,1,1]代表处理第五列数据，第一列是温度或循环参数，最后一个参数1或0，表示横轴参数为第一列或第零列。

**合并目录树**

```python
from pathlib import Path
import shutil
file = Path('.').rglob('cl*/*/*/out.dat')
for i in file:
    apd = i.relative_to(i.parts[0])
    ## create same dir tree of cl*
    apd.parent.mkdir(parents=True, exist_ok=True)
    ## append cl*
    with open(i, 'r') as src, open(apd, 'a') as dst:
        dst.write(src.read())
#delete the original cl* dir
rm_dir = Path('.').rglob('cl*')
for i in rm_dir:
    shutil.rmtree(i)
```

1. 先使用mkdir cl{1..20}，创建cl1，cl2，cl3...cl20
2. 执行上述代码代码可以合并所有数据

**检测脚本**

```shell
#! /bin/bash
bins=30
mc_eq=100000
mcs=100000

j4=0.05

x_i=.18000
x_f=.23000
x_step=0.01000
STOP_FILE="stop"

ifort atv2.f90
rm log
until [[ -f "$STOP_FILE" ]]; do
	cur=$(squeue -u $USER|wc -l)
	if (( $cur < 20 )); then
		for ll in 4 8 16
		do
			temp=$x_i
			mkdir -p $ll ; cd $ll
			
			while(( $(echo "$temp <= $x_f" | bc ) ))
			do
				echo $(date +%N) > ../seed.in
				mkdir -p temp$temp ; 
				cp ../a.out  ../job ../seed.in  temp$temp
				cd temp$temp
				echo "$ll $temp $j4 $mc_eq $bins $mcs" > read.in
				#./a.out  &
				sbatch -J $ll-$temp job
				#echo -e "$temp " " \c"
				temp=$(echo "$temp + $x_step" | bc)
				cd ..
				sleep 0.1
			done
			echo "done"
			cd ..
		done
	else
		echo "当前任务数 $cur ，等待10秒后继续提交任务..." #>> log
		sleep 10
	fi
done

echo "检测到停止文件 '$STOP_FILE'，正在退出循环..." >> log
rm -f "$STOP_FILE"


```
